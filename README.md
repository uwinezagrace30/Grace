# My Portfolio — Personal Portfolio

## Description
This is my personal portfolio website showcasing my background, skills, education, experience, and career journey as an Information Technology professional. 

The portfolio provides a clean, comprehensive overview of my technical skills, professional history, and achievements in the IT field.

## Features
* **Home** — Introduction and personal profile
* **About Me** — Background, education, and professional information
* **Skills** — Technical competencies and expert domains
* **Experience** — Professional work experience and roles
* **Contact** — Ways to get in touch with me
* **Modern Responsive Design** — Works on desktop, tablet, and mobile devices
* **Animated UI** — Modern animations and interactive elements

## How to Run It
You can view the live portfolio through GitHub Pages:

**GitHub Pages:**  
https://github.io

You can also download or clone the repository and open the `index.html` file in a web browser.

## How to Install
Clone the repository using Git:

```bash
git clone https://github.com
```

Then move into the project folder:
```bash
cd Grace
```

Open `index.html` in your browser.
